# Sioux Falls water sites

Two separate lead sites live in this repo. Each folder is its own Astro project and its own Vercel project.

| Folder | Site | Domain | Vercel project |
| --- | --- | --- | --- |
| `water-filters/` | Sioux Falls Water Filters | siouxfallswaterfilter.com | siouxfalls-waterfilter |
| `water-filtration/` | Sioux Falls Water Filtration | siouxfallswaterfiltration.com | siouxfalls-waterfiltration |

Keep the copy on the two sites different. Do not paste text from one into the other.

Each folder has its own README with commands and where to change the phone number.
